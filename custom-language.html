Marila Programming Language

Domain-Specific Language • Mathematical Visualization

domain-specific language python mathematical documents animation vector geometry

Overview

Marila is a Python-backed domain-specific language for mathematical documents, motion graphics, and Euclidean vector diagrams. Its concise syntax supports document, video, and image file types, with a command-line workflow for syntax checking and rendering output.

Goal: Make mathematical writing and visual explanations programmable through one expressive, purpose-built language.

Language Formats

  • Documents: Typeset mathematical papers, definitions, equations, and theorems.
  • Video: Create Manim-style shape animations and animated mathematical plots.
  • Images: Describe TikZ-style Euclidean diagrams with points, lines, angles, and shapes.

Command-Line Workflow

Marila scripts are checked and rendered through the Python CLI. Documents and animations can be compiled to HTML, while vector diagrams can be rendered to SVG for use in mathematical explanations.

Technologies & Tools

Implemented on top of Python, with a command-line interface that checks Marila source files and renders documents to HTML, animations to HTML, and vector diagrams to SVG.
